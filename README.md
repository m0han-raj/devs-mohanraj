## Featured Projects

- [**surfai**](https://github.com/m0han-raj/surfai): A personal AI assistant for browsing the web: Chrome Side Panel agent with semantic DOM understanding, deterministic safety layer, and AI-aware memory.
- [**aqua-seq**](https://github.com/m0han-raj/aqua-seq): Risk-aware water safety screening from physicochemical parameters. Decision threshold chosen around the cost of a missed unsafe sample, benchmarked against a rule built from verified WHO/BIS/EPA limits.
- [**DINO**](https://github.com/m0han-raj/DINO): Self-supervised Vision Transformer (DINO) implemented from scratch in PyTorch with student-teacher distillation, multi-crop augmentation, linear probing, and attention map visualization.
- [**tredence_analytics**](https://github.com/m0han-raj/tredence_analytics): A PyTorch feed-forward network that learns to prune itself during training. Every weight is paired with a learnable gate and an L1 penalty drives unnecessary gates to zero.
- [**ReAct-reasoning-and-acting**](https://github.com/m0han-raj/ReAct-reasoning-and-acting): A research implementation of the ReAct framework (Reasoning + Acting) for language models, combining LLM reasoning with actionable steps to improve problem-solving performance.
- [**lifelong-LLM-agents**](https://github.com/m0han-raj/lifelong-LLM-agents): A lifelong agent that stores episodic and semantic memory and uses it in future conversations, based on the "Generative Agents: Interactive Simulacra of Human Behavior" paper.
- [**MedRAG**](https://github.com/m0han-raj/MedRAG): Medplus, a diabetes chatbot that answers diabetes-related queries using a RAG model that retrieves information based on context.
- [**neuroNER**](https://github.com/m0han-raj/neuroNER): A BiLSTM-CRF model for Named Entity Recognition in Tamil text using character-level and word-level embeddings.
- [**MedivUe**](https://github.com/m0han-raj/MedivUe): A basic U-Net implementation for segmentation of medical images.
- [**EN2DE-Transformer**](https://github.com/m0han-raj/EN2DE-Transformer): A basic transformer used to translate English to German.
- [**ResNet34**](https://github.com/m0han-raj/ResNet34): A basic ResNet model for image recognition on the CIFAR-10 dataset.
- [**Solar**](https://github.com/m0han-raj/Solar): A Gemini clone built with React.js.
